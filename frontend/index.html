Hierarchy

Name Search (BST)

Every file and directory name is indexed in a Binary Search Tree (BST 1). Exact search follows a single root-to-node path.

File Size Search (Size BST)

Every file is indexed in a second Binary Search Tree (BST 2) keyed by size. Range queries prune branches outside [min, max], and files with identical sizes are chained in linked lists.
